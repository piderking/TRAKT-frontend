# TRAKT Web Dashboard (TRAKT-frontend)

The analytical web portal for the Trakt Modular Ecosystem built with Next.js 14, React, Tailwind CSS, and Recharts.

## Features
- **Node Dashboard & Live Scrobble Feed**: System status cards, warm cache hit monitors, daemon connections.
- **Analytics Dashboard**: Year in review watch volume, genre breakdown, viewing velocity heatmaps.
- **Dynamic List Builder**: Interactive filter rules (e.g. Runtime > 90m AND Rating > 8.0) and JSON export.
- **System Topology Inspector**: Microservice ping latencies, cache flush triggers, container health.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build production bundle:
   ```bash
   npm run build
   ```
